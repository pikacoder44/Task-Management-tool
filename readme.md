# 📝 Task Management Tool

A simple Task Management Web Application built using Node.js, Express.js, and EJS. It allows users to create, read, update, and delete (CRUD) tasks. This project demonstrates the basic structure and functionality of a full-stack Node.js app using server-side rendering.

# 🚀 Features

- Add new tasks with title and description

- View a list of all tasks

- Mark tasks as completed

- Edit task details

- Delete tasks

- Responsive and clean UI with EJS templating

# 📦 Tech Stack

- Backend: Node.js, Express.js

- Templating Engine: EJS

- Database: MongoDB (Optional: You can also use in-memory array or a file-based storage)

- Styling: CSS/Bootstrap (as per your design)
